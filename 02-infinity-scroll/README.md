# Infinity Scroll

A photo gallery that loads more photos from the Unsplash API as you scroll down.

**[Live demo](https://souravxdev.github.io/JavaScript-Projects/02-infinity-scroll/)** · 🚧 In progress

## Features

- [ ] Grid of photos from the [Unsplash API](https://unsplash.com/developers)
- [ ] More photos load automatically near the bottom of the page
- [ ] Loader while the first photos are loading
- [ ] Each photo links to its page on Unsplash
- [ ] Responsive layout

## Built with

HTML, CSS and vanilla JavaScript.
